# API Response Visualizer

Paste any JSON API response and instantly see it as a clean UI.

No config. No schema. No setup. Just paste and view.

## What it does

- Detects the shape of your JSON automatically
- Renders it as the most appropriate UI: table, cards, key-value, tree, or chart
- Lets you switch between renderers manually
- Works with REST APIs, GraphQL responses, config files, anything valid JSON

## Built with

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Recharts

## Run locally

npm install
npm run dev

Open http://localhost:3000
